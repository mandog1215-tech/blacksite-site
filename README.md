# Blacksite public site

The project's public hub. It is a *view* of the development record,
never a second source of truth.

## Standing rules (adopted 2026-11-01, same as the other studio sites)

1. **Status changes require evidence.** Nothing becomes "released",
   "complete", or "verified" because a page changed — only when the
   development record supports it. In particular, version 1.5.0 is
   HELD and must never be presented as published or downloadable.
2. **Known gaps remain visible until genuinely resolved** (history
   scope, un-re-run Windows gates, stale internal instructions).
3. **Intent stays labelled as intent.** Episode 2 is recorded design
   intent, not a scheduled feature.
4. **Three states stay separate:** the game today (verified), what is
   being built (active work), and the long-term intent.

If anything here conflicts with the development record, the record
is right and the site gets corrected.
